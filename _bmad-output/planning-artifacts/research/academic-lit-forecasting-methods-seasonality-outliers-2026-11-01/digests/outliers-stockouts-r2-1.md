## Worked example(s) / formulas
None requested. Rule candidates (each is a design option, with the sourcing status stated):
- Exclude stockout weeks and fill them (row 6, 8): supported by FPP3 (use data after the last gap, or interpolate). Interpolation by a model such as ARIMA is FPP3's example, not a simple moving average.
- Moving average over the last N valid weeks: no retrieved source states this rule. It is an inference. Consistent with the "drop" option in row 13 and with FPP3's "use only data after the last missing value" (row 8) as the two named routes. No source found comparing "shrink the window" vs "skip back to N valid".
- Outlier rule: 3 x IQR from the quartiles (row 7). A median-based rule would be fragile for intermittent items (see Not found).
