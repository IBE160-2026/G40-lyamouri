## Worked example(s) / formulas (only if asked)
Not asked for as a deliverable; formulas are in the rows above (Hampel: row 7; tabular CUSUM: row 15; FPP IQR fences: rows 1-2). Note that FPP's IQR rule is applied to STL remainders, not raw values (row 1).

Hand-check arithmetic for a Hampel window (derived, not a sourced claim, but follows row 7 directly): window values 10, 12, 11, 40, 9 -> median 11; absolute deviations 1, 1, 0, 29, 2 -> MAD 1; scaled 1.4826; limit 11 +/- 3 x 1.4826 = 11 +/- 4.45; 40 is flagged. If the window were 0, 0, 0, 6, 0, the median is 0 and MAD is 0, so any nonzero value is flagged (this follows from the formula in row 7; no source read discusses it, see row 10).
