## Worked example(s) / formulas
Placeholder pattern consistent with rows 4, 5, 18 (design suggestion, not a sourced claim): the model returns text containing named placeholders such as {peak_value} plus a JSON schema; the application substitutes numbers from its own data, then checks that every placeholder in the template exists in the data and every number in the final string was inserted by the app. Schema validation (rows 1, 4) checks shape only; row 3 shows output can also be incomplete or a refusal, so a deterministic template fallback is needed anyway.
