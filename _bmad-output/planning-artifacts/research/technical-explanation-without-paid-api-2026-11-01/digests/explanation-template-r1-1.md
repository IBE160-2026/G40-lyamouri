## Worked example(s) / formulas
None requested. Design implication drawn only from the rows above (my inference, labelled as such): for candidate 4, the application should build the numeric facts and the template text deterministically (row 1, 16), let an optional model rewrite only wording, and then run a check that every number (normalised, so 1,000 equals 1000 equals 1M-style variants, row 10) in the rewrite also appears in the template text; if the check fails, show the template text. Row 8-9 show a plain "number present" check does not catch a real number used in the wrong context, so the check should also compare the multiset of numbers and their adjacent labels or units, or the rewrite should be restricted to filling named placeholders.
